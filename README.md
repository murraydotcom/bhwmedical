# bhwmedical.org

Public **marketing + education** site for **Baltimore Healthcare and Wellness (BHW Medical Group)** — Baltimore, MD.

Zero-build static HTML on the shared **Opal & Ironstone** brand tokens (`assets/bhw-tokens.css`). Deploy on Netlify (publish `.`, no build), pointed at `bhwmedical.org`.

## Sitemap
- `index.html` — home (hero, programs, education teaser, local `MedicalClinic` schema)
- `programs.html` — Primary Care · Mind & Mood · Flow · CharmEd · Chronic Care
- `education.html` — education hub (pillars: nutrition, sleep, mental health, gut health, movement, pediatrics, labs) — fill from Drive
- `insurance.html` — accepted plans
- `about.html`, `contact.html` (new-patient inquiry → Front Desk triage queue via crewOS `portal-message`)

## Related sites
- **myBHW.com** — Care Connect patient portal
- **crewhq.bhwmedical.org** — staff (crewOS / HQ)
